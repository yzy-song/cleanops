## 二、B2B 管理 SaaS — 直接竞品

### 1. Jobber（市场龙头）

| 维度 | 详情 |
|------|------|
| **定位** | 中小型服务公司一站式管理 |
| **价格** | $39–$599/月（年付），加用户 $29/人 |
| **核心功能** | 排班调度、在线预约、报价转工单、发票+收款、Client Hub 自助门户、QuickBooks 同步、AI 接听电话 |
| **优势** | 最完整的全流程；Client Hub 客户自助；SMS 自动化；成熟生态 |
| **弱点** | 价格阶梯陡峭（10 人团队轻松过 $700/月）；无照片 AI 估价；无原生电话系统 |
| **爱尔兰适配** | ❌ 无 Eircode、无 Stripe Connect、无 13.5%/23% VAT 自动区分 |

### 2. Housecall Pro（增长型）

| 维度 | 详情 |
|------|------|
| **定位** | 多 crew 规模化运营 |
| **价格** | $59–$329/月，加 add-ons 轻松 $400–$600+ |
| **核心功能** | GPS 追踪、路线优化、营销自动化、消费金融分期、Google LSA 集成 |
| **优势** | 最强的营销+增长工具；GPS+路线；最大集成市场 |
| **弱点** | 核心功能锁在高级版；Trustpilot 跌至 3.2 分；客服难联系；贵 |
| **爱尔兰适配** | ❌ 同上，且更偏美国市场 |

### 3. ZenMaid（清洁专用）

| 维度 | 详情 |
|------|------|
| **定位** | 纯住宅 maid service |
| **价格** | $19/月 + $4/人（入门），$39/月 + $14/人（成长） |
| **核心功能** | 清洁专用调度、周期性工单、钥匙管理、SOS 预警、小费、清洁检查清单 |
| **优势** | 最懂清洁行业（创始人来自清洁行业）；最便宜；在线预约 5.0 评分 |
| **弱点** | 只做住宅清洁；SMS 按条收费很贵；非美国用户会计/税务不适用 |
| **爱尔兰适配** | ❌ 无 Stripe Connect、无 VAT 区分、无 Eircode |

### 4. Workever（英国）

| 维度 | 详情 |
|------|------|
| **定位** | 英国中小清洁/服务团队 |
| **价格** | £29–£39/用户/月 |
| **核心功能** | 报价→发票全流程；Xero/QuickBooks/Sage 集成；英国合规 |
| **优势** | 英国本地化好；全流程覆盖 |
| **弱点** | 界面陈旧；移动端弱；功能深度不如 Jobber |
| **爱尔兰适配** | ⚠️ 部分（英国 VAT 类似但不完全相同） |

### 5. ProCleanerUK（英国）

| 维度 | 详情 |
|------|------|
| **定位** | 微型清洁公司/独立清洁工 |
| **价格** | £49.99–£99.99/月 |
| **核心功能** | 离线移动端、AI 排班、路线优化、客户自动沟通 |
| **优势** | 离线可用（乡村/地下室场景）；固定价格不随人数涨 |
| **弱点** | 功能相对简单；品牌知名度低 |
| **爱尔兰适配** | ❌ 偏英国 |

### 6. CleanManager（丹麦，偏商业清洁）

| 维度 | 详情 |
|------|------|
| **定位** | 商业清洁合同管理 |
| **价格** | £167–£1,215/月 |
| **核心功能** | 合同管理、质量审核+照片、合规 KPI 报告 |
| **优势** | 强合同管理+质量审计 |
| **弱点** | 贵；偏大型商业清洁公司；不适合住宅清洁 |
| **爱尔兰适配** | ❌ |

### 7. Allclean（英国）

| 维度 | 详情 |
|------|------|
| **定位** | 住宅+商业+加盟连锁 |

| **核心功能** | 集成支付、AI 语音客服（接电话+预约）、推荐+忠诚度系统 |
| **优势** | AI 电话客服是差异化功能；加盟模式支持 |
| **弱点** | 起步价贵；不适合小团队 |
| **爱尔兰适配** | ❌ |

### 8. Connecteam（以色列，通用 HR+运营）

| 维度 | 详情 |
|------|------|
| **定位** | 无桌面员工的 HR+运营平台 |
| **价格** | 免费（10 人以下）→ $29/月起 |
| **核心功能** | 排班、考勤 GPS 打卡、聊天、培训、合规文档 |
| **优势** | 免费版对小团队友好；强员工管理 |
| **弱点** | 不是清洁专用；无 CRM/报价/发票 |
| **爱尔兰适配** | ⚠️ 通用型，无本地化 |

## 三、B2C 预约平台 — 间接竞品

这些平台跳过清洁公司，直接连接客户和清洁工。**CleanOps 的客户可能在这些平台上接单，与 CleanOps 形成替代关系。**

### 1. eMop.ie（爱尔兰）

| 维度 | 详情 |
|------|------|
| **定位** | 都柏林清洁预约平台（B2C 撮合） |
| **价格** | 客户 €23/小时起 |
| **功能** | 24/7 预约、按实际时间付费、APP 管理、环保清洁、返现 €150 |
| **特点** | 纯撮合模式，不服务清洁公司；针对都柏林市场 |
| **优势** | 爱尔兰本地最强品牌认知；APP 体验好；Pay-as-You-Go 灵活 |
| **弱点** | 客户不属于清洁公司（平台掌控客户关系）；清洁工只是平台的执行者 |

### 2. Helpling / Hassle.com（爱尔兰覆盖）

| 维度 | 详情 |
|------|------|
| **定位** | 全欧洲清洁预约平台 |
| **价格** | 按小时+抽成 |
| **功能** | 在线预约、受保清洁工、应用内聊天、评分评价 |
| **特点** | Hassle.com 是 Helpling 的爱尔兰品牌；清洁工需面试+背景调查 |
| **优势** | 欧洲最大；品牌信任度；规模效应 |
| **弱点** | 高抽成比例（清洁工到手少）；标准化服务缺乏差异化 |

### 3. Housekeep（英国）

| 维度 | 详情 |
|------|------|
| **定位** | 英国家庭清洁预约 |
| **特点** | 与 Helpling 竞争英国市场 |
| **爱尔兰适配** | 目前仅英国 |

### 4. Homeaglow（美国，全球扩张中）

| 维度 | 详情 |
|------|------|
| **定位** | 美国家庭清洁（会员制） |
| **特点** | 低价会员订阅模式（$19/月 + 每小时 $18） |
| **争议** | 劳工权益争议大；清洁工抱怨工资过低 |

## 四、CleanOps vs 竞品 — 差距矩阵

### CleanOps 的优势 ✅

| 能力 | 竞品状态 | CleanOps |
|------|----------|----------|
| **爱尔兰本地化** | 所有国际竞品都不支持 | ✅ Eircode、13.5%/23% VAT、Stripe Connect |
| **Google Maps + 地理编码** | Housecall 有 GPS 但无 Eircode | ✅ 邮编→经纬度自动转换 |
| **智能排班算法** | 大部分是手动拖拽 | ✅ 贪心打分算法 + TSP 路径排序 |
| **Stripe Connect 平台支付** | Jobber 只有 Stripe 直连 | ✅ Connect 模式（平台抽成） |
| **客户 Magic Link 登录** | Jobber/HCP 有客户门户但需密码 | ✅ 无需密码，24h 有效 |
| **价格** | $39–$599+/月 | ✅ 自有部署零月费 |

### CleanOps 的差距 ❌

| 能力 | 竞品怎么做 | CleanOps 状态 |
|------|-----------|---------------|
| **移动端 APP** | Jobber/HCP/ZenMaid 都有原生 APP | ❌ 没有 |
| **SMS 提醒** | Jobber 标配 SMS 自动提醒 | ❌ 只有邮件，无 SMS |
| **在线预约挂件** | Jobber 可嵌入网站 | ❌ 独立页面，无嵌入式 widget |
| **客户自助门户深度** | Jobber Client Hub 可审批报价/付款/请求服务 | ⚠️ 基础版（查看+改期+取消） |
| **QuickBooks/Xero 深度集成** | Jobber/HCP 双向同步 | ⚠️ Xero 仅有基础集成 |
| **营销自动化** | HCP 有完整营销套件 | ❌ 完全没有 |
| **AI 功能** | Allclean AI 语音客服、Jobber AI 接听 | ❌ 没有 |
| **照片→报价 AI** | MyQuoteIQ 等工具 | ❌ 没有 |
| **离线模式** | ProCleanerUK 有离线 APP | ❌ 无离线支持 |
| **多语言/多币种** | 多数支持 | ❌ 硬编码英文 |
| **报告深度** | Jobber/HCP 有 20+ 报告模板 | ⚠️ 基础版（Payroll/VAT/工时） |
| **客户 APP** | eMop/Helpling 有原生客户 APP | ❌ 响应式 Web 代替 |

## 五、战略建议

### 短期可追赶（1-3 个月）

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P0 | **嵌入式在线预约 Widget** | Jobber 有此功能，是获客核心入口 |
| P0 | **报价邮件含客户行动按钮** | 刚补上邮件通知，需增强 CTA |
| P1 | **客户门户 UI/UX 提升** | 对标 Jobber Client Hub 的体验 |
| P1 | **更多报告**（客户留存/利润分析/清洁工效率） | 竞品都有 20+ 报告 |

### 中期建设（3-6 个月）

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P2 | **SMS 提醒**（Twilio/MessageBird） | 爱尔兰 SMS 到达率高 |
| P2 | **移动端 PWA 或 APP** | 清洁工在路上需要 |
| P2 | **i18n 多语言** | 爱尔兰市场可扩展至多语言 |
| P2 | **Xero 深度集成** | 爱尔兰 Xero 用户量大 |

### 长期差异化（6-12 个月）

| 优先级 | 功能 | 理由 |
|--------|------|------|
| P3 | **AI 照片估价** | 差异化大杀器 |
| P3 | **路线优化升级**（Distance Matrix API） | 当用户量足够时升级 |
| P3 | **营销工具套件** | 邮件营销 + 客户留存分析 |

## 六、核心结论

1. **CleanOps 的护城河是爱尔兰本地化** — 没有一个国际竞品能正确处理 Eircode + 双重 VAT + Stripe Connect。这是不可替代的。

2. **最大的功能差距在客户体验层** — 嵌入式预约、SMS、移动端、客户门户深度，这些竞品已经做得很好而我们还没有。

3. **eMop/Helpling 不是直接竞品** — 它们是 B2C 撮合平台，抢的是清洁公司的客户。CleanOps 应该帮清洁公司对抗这两家（给他们更好的数字化工具），而不是跟它们竞争。

4. **价格是巨大优势** — 竞品 $39–$599/月，CleanOps 自有部署零月费。这是向小型清洁公司推广时的杀手锏。
