# CleanOps 角色权限矩阵

## 三种角色

| 角色 | 真实身份 | 核心职责 |
|------|---------|---------|
| **ADMIN** | 清洁公司老板 | 定价策略、雇佣管理、财务总览、公司配置 |
| **MANAGER** | 运营经理/主管 | 排班调度、客户关系、报价发票、团队协调 |
| **WORKER** | 清洁工 | 查看今日任务、到岗打卡、完成清洁、下班签退 |
